# Horsepower ↔ Torque Calculator

A Python calculator that converts engine torque and RPM into horsepower.

## Formula

HP = (Torque × RPM) / 7127

## Features

- User input
- Professional output
- Metric horsepower calculation
- Rounded output

## How to Run

python main.py

## Example

Torque: 350 Nm

RPM: 6000

Horsepower = 294.65 HP
